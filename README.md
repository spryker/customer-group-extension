# CustomerGroupExtension Module
[![Latest Stable Version](https://poser.pugx.org/spryker/customer-group-extension/v/stable.svg)](https://packagist.org/packages/spryker/customer-group-extension)
[![Minimum PHP Version](https://img.shields.io/badge/php-%3E%3D%208.3-8892BF.svg)](https://php.net/)

The module provides plugin interfaces for extending CustomerGroup module functionality: additional tabs and form fields on the customer group Back Office form, and post-save steps executed in the customer group save transaction.

## Installation

```
composer require spryker/customer-group-extension
```
